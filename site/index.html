Say “echo echo.”
Then just talk.

Echo is an always-on voice agent for your Mac. It listens for its wake word, holds a natural back-and-forth conversation, and farms real work out to background agents — weaving the results back in while you speak.

What a session feels like

Wake it, talk like you would to a person, say “that’s it” when you’re done. Meanwhile, workers write documents live into a browser workspace you can watch update in real time.

echo echo … help me plan dinners this week, I’m thinking pad thai one night.
→ recipe.search dispatched · grocery.md created in the live workspace
Found three solid pad thai recipes — I started a grocery list with the one that skips tamarind paste. What else are we cooking?
something with halloumi. and drop the fish sauce, we’re out.
→ grocery.merge updates the list while the conversation continues
Done — fish sauce is out, halloumi traybake is in for Thursday. The list is on your screen.
that’s it.

How it works

Four pieces, all local except the voice model. Idle listening costs ~2% of one core and $0 in API.

01 Wake word

Vosk keyword spotting for “echo echo” — fully offline, open source, no accounts, no training. Sessions only exist between the wake word and “that’s it.”

02 Voice loop

OpenAI Realtime speech-to-speech with semantic voice-activity detection, barge-in (interrupt it mid-sentence), and auto-reconnect so the daemon never dies.

03 Background workers

The conversation dispatches tasks — doc edits, recipe search, learning outlines — to async workers. Results are ranked and injected back at natural turn boundaries.

04 Live workspace

Everything workers produce is markdown, rendered live in a browser tab: transcript and activity on the left, your documents updating on the right.

Install in five minutes

You need macOS, Python 3, headphones, and an OpenAI API key.

  1. Download the release above (or clone the repo) and open a terminal in the folder.
  2. Install the environment and fetch the offline wake-word model (~40 MB).
  3. Add your key, run a mic check, and start the daemon.
# from the project folder
uv venv .venv && source .venv/bin/activate
pip install -r requirements-mac.txt
bash scripts/fetch_models.sh

# your OpenAI API key (gitignored, loaded at startup)
echo 'OPENAI_API_KEY=sk-...' > .env.local

python3 echo.py --mic-check   # RMS meter should move when you speak
python3 echo.py --voice       # put your headphones on first

Then open http://127.0.0.1:8765/ for the live workspace, say “echo echo”, and talk. Full runbook, troubleshooting table, and AirPods notes are in the README.

🎧
Headphones required. There’s no echo cancellation over the raw WebSocket — on speakers, Echo hears itself and barge-in goes haywire. AirPods or any headphones work.

Built for tinkering

Echo is a prototype you can read in an afternoon and bend to your own use cases.

Runs headless, keyless

The whole orchestrator/worker loop runs with no audio and no API key — a text REPL, scripted fixtures, and a 150+ test suite. Develop anywhere, voice only needs the Mac.

Records every session

Each voice session saves a stereo review mix (you left, Echo right), transcripts, and an event timeline — so you can hear exactly what happened and turn gaps into fixes.

Add your own workers

Workers are small async functions behind a typed task queue. If a CLI coding agent is on your PATH, a code task kind registers automatically.
